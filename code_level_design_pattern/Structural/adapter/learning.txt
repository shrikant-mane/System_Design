What is an Adapter?

An Adapter is an object that sits between two incompatible interfaces and converts one
interface into another interface that the client understands.


Wall Socket
    │
    │ 220V AC
    ↓
┌───────────┐
│  Adapter  │
└───────────┘
    │
    │ 5V DC
    ↓
   Phone

The adapter doesn't fundamentally change what the phone does.
It converts the interface/format so that the two systems can work together.

Adapter is a structural design pattern used when two components have incompatible
interfaces. It acts as a bridge between the client and an existing class by converting
the existing class's interface into the interface expected by the client.
A common real-world example is integrating different third-party payment providers that
expose different APIs behind a common payment interface
